Yerel çalıştırma

  1. Java 17 ve Maven gerekli. Projenin dosya tabanlı H2 veritabanı kullanıcı home dizininde tutulur.
  2. Kaynakta spring.datasource.password anahtarı görünür değil; DBService bu özelliği zorunlu okuyor. Demo ortamınıza uygun değeri yalnızca yerel ortam değişkeni/secret ile verin; repoya eklemeyin.
  3. Wrapper betiği mevcut olsa da bu checkout'ta `.mvn/wrapper` destek dosyaları yok. Wrapper dosyaları tamamlanırsa çalıştırma komutu aşağıdaki gibidir. Yerel Maven kuruluysa alternatif komutu kullanın.
SPRING_DATASOURCE_PASSWORD='<yerel-demo-veritabani-parolasi>' ./mvnw spring-boot:run
# Alternatif: Maven kuruluysa
SPRING_DATASOURCE_PASSWORD='<yerel-demo-veritabani-parolasi>' mvn spring-boot:run
Dikkat Yukarıdaki parantezli değer yer tutucudur. Uygulama `8090` portunu kullanır. `./mvnw` betiği tek başına yeterli değildir: wrapper destek dosyaları eksik olduğu için mevcut checkout'ta wrapper'ın çalışacağı doğrulanmadı. `SPRING_DATASOURCE_PASSWORD` değerini mevcut yerel H2 dosyanızla uyumlu seçin; veritabanı dosyasını veya gerçek parolayı paylaşmayın.

Demo ortamı uyarıları

  • [application.properties](../src/main/resources/application.properties) içinde AES/HMAC anahtarları tanımlı; eğitim dışı kullanımda bunları secret management'a taşıyın. Dokümanda gerçek anahtar değerleri tekrarlanmaz.
  • CSRF kapalı, HTTPS/SSL ayarı yoktur. HTTP Basic kimlik bilgilerini yalnızca loopback/izole yerel laboratuvarda kullanın; ağa açık ortama taşımayın.
  • Kayıt DTO'su rol listesi kabul eder ve serviste entity'ye map edilir. Authorization demosunda yalnızca atılabilir bir eğitim veritabanı kullanın.
  • Rate limiter tüm isteklerce paylaşılan tek bean olarak yapılandırılmıştır; 5/dakika sınırı sınıfın kullanıcı bazlı brute-force koruması olduğu anlamına gelmez. Sınıfın tamamı limiti tüketebilir.
  • Log filtresi SessionId ve istemci metadata'sı logluyor. Dersi izole ortamda yapın; logları dağıtmayın ve hassas gerçek kullanıcı verisi kullanmayın.
  • H2 Console bağımlılığı bulunması console'un etkin olduğunu kanıtlamaz; kaynak properties'te etkinleştirme ayarı görünmüyor.
  • Repository'de kasıtlı açık/güvenli branch çifti yok. Kod örnekleri gerçek haliyle alıntılanacak; güvenli iyileştirme bulunmayan başlıklarda öneri açıkça “Önerilen Düzeltme” olarak ayrılacak.
Eğitmen Notu Rol denemelerinde konfigürasyondaki `hasRole("product")` / `hasRole("note")` kontrolleri ile `CustomerService`'in DB rol adlarını authority'ye dönüştürme biçimini birlikte inceleyin. Gerçek kayıtların ve authority adlarının eşleştiği doğrulanmadan beklenen başarılı isteği garanti etmeyin.

Ortak tasarım ilkesi

Dil değişse de karar zinciri aynıdır: girdiyi doğru canonical biçime getir, amaçlanan formata allowlist ile doğrula, kimliği doğrula, kaynağa göre yetkiyi kontrol et, doğru bağlamda güvenli çıktı üret, secret'ları koru ve davranışı test et. Java framework kontrolleri C++'ta otomatik oluşmaz; C++'ın bellek güvenliği ve sahiplik modeli ise HTTP authorization yerine geçmez.

İleri okuma: Buffer Overflow, statik/dinamik analiz, eksik demo önerileri ve sınav haritası.
